# Activos Pro - Sistema de Gestión de Inventario Tecnológico

Este es un sistema profesional de grado diseñado para la gestión, seguimiento y mantenimiento de activos tecnológicos (Computadores, Monitores, UPS).

## 🚀 Características Principales

- **Dashboard Administrativo**: Resumen en tiempo real de activos, usuarios y mantenimientos.
- **Gestión Multi-Hardware**: Soporte para múltiples módulos de memoria RAM (con validación de compatibilidad) y múltiples unidades de disco.
- **Hoja de Vida Técnica**: Trazabilidad completa de mantenimientos, incidentes e intervenciones por equipo.
- **Catálogo Técnico**: Módulo dinámico para definir marcas, modelos, CPU y componentes.
- **Control de Acceso (RBAC)**: Roles de Administrador, Técnico y Estándar.
- **Software & Licenciamiento**: Registro de versiones y claves (Product Keys) de Windows y Office.

## 🛠️ Tecnologías

- **Framework**: Next.js 15 (App Router)
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS + ShadCN UI
- **Validación**: Zod
- **Gráficos**: Recharts
